# Demo scripts

Concept prototype; all data is illustrative, generated from the Tenant Packs and a seeded population. Say so at the start of any demo.

Every tenant is seeded on **day 23 of a 30-day cycle, dated the day you load it** (or press Reset demo). Dates below assume 23 Nov 2026.

- [leadership-walkthrough.md](leadership-walkthrough.md): the 12-minute leadership run, Clay first.
- [12-minute-demo.md](12-minute-demo.md): the Phase 8 presenter script with notes and the pitch mapping; run it from **Present** in the top bar.
- [clay.md](clay.md), [builderco.md](builderco.md), [apico.md](apico.md): what each pack shows and where to click. SeatCo (seats plus a credit pool) runs the same journeys.
- Per phase: [phase-2-credits-hub.md](phase-2-credits-hub.md), [phase-3-onboarding-and-tour.md](phase-3-onboarding-and-tour.md), [phase-4-ask-cb.md](phase-4-ask-cb.md), [phase-5-growth-workbench.md](phase-5-growth-workbench.md), [phase-6-evals.md](phase-6-evals.md), [phase-7-mcp-agents-embed.md](phase-7-mcp-agents-embed.md), [phase-8-scale-and-demo.md](phase-8-scale-and-demo.md).

The in-app **Demo script** button (top bar) runs the same steps for whichever tenant is active and switches persona, tab and horizon for you.
